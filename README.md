# SkyShield – Aviation Safety & Incident Analysis System

A decision-support web app for aviation safety officers. It lets authorized
users report incidents, view safety dashboards, find similar historical
incidents, and see possible root-cause suggestions.

> **Important:** SkyShield is an advisory tool only. It does not predict
> crashes. All results must be reviewed by an authorized safety professional.

## Current status
- Front-end prototype (HTML, CSS, JavaScript)
- Login and AI analysis are **simulated** (demo only)
- Django backend: **planned**
